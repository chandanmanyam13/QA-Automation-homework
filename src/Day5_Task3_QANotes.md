# Basic QA Notes

## 1. QA (Quality Assurance)

**QA (Quality Assurance)** is the process of ensuring that a software product meets defined quality standards and works as expected.

**Example:**
A QA tester checks whether a banking application allows users to log in, view their account balance, and transfer money correctly.

---

## 2. Test Case

A **test case** is a set of steps, test data, and expected results used to verify a specific feature or functionality.

**Example: Login Test Case**

* **Test Case:** Verify login with valid credentials
* **Steps:**

  1. Open the login page.
  2. Enter a valid username.
  3. Enter a valid password.
  4. Click the Login button.
* **Expected Result:** User should successfully log in and see the home page.

---

## 3. Bug

A **bug** is a defect or error in software that causes the application to behave incorrectly or unexpectedly.

**Example:**
A user enters the correct username and password, but the application displays **"Invalid username or password."** This is a bug because valid credentials should allow the user to log in.
